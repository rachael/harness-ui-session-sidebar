# Mascot artwork provenance

`sprites.json` contains nine ASCII mascot fan-art variants shared by the harness adapters. Claude agents wrote them for an earlier info-pane plugin; the existing frames were retained when this project's contributor introduced the shared sprite/action catalog in commit `17495c7`. The original creation record does not establish how the base silhouette was drawn. Treat these as renditions of the Claude Code mascot, whose underlying character design is associated with Anthropic.

The recorded source commit does not establish a separate license for the underlying character artwork. Generated TypeScript and native patch copies have the same provenance as this catalog.
